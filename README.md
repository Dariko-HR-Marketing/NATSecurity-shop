# 🛡️ NAT Security - Telegram Mini App & Bot

Buxoro shahar va viloyati bo'ylab professional xavfsizlik, videokuzatuv kameralari va SKUD (Kirishni nazorat qilish) tizimlari rasmiy Telegram Mini App do'koni.

## 🚀 Imkoniyatlar
- 📹 **Videokuzatuv kameralari katalogi**: Hikvision, Dahua, ColorVu 24/7, PTZ 360°, ichki va tashqi modellar.
- 🚪 **SKUD tizimlari**: Face ID terminallari, smart biometrik qulflar, tripod turniketlar va avtomatik shlagbaumlar.
- 🧮 **Onlayn Smeta Kalkulyatori**: Obyekt turi, kameralar soni, sifati va xotirasiga qarab montaj bilan birgalikda narxni avtomatik hisoblash.
- 🛠️ **Servis xizmatlari**: Obyektni bepul ko'rikdan o'tkazish, montaj, mobil monitoring va texnik profilaktika.
- ⚙️ **Admin Panel**: Tushgan buyurtmalar va smetalarni boshqarish.
- 📲 **Telegram integratsiyasi**: Telegram WebApp SDK, HapticFeedback, Telegram `MainButton`.

## 📂 Fayllar tuzilishi
- `index.html` — Mini App'ning to'liq interfeysi (UI/UX, kalkulyator, savatcha).
- `bot.py` — Telegram bot kodi (@NATSecurityShop_bot).
- `logo_light.jpg` — NAT Security rasmiy oq fonli logotipi.
- `logo.jpg` — NAT Security to'q fonli logotipi.
